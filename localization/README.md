**TEAM050_ru-en_v2.xlsx** — актуальный единый файл для переводчика: 407 строк: 385 активных и 22 архивных; в том числе все 330 ID первого пакета и 77 новых. Новые строки отмечены в колонке D. Ранее выполненный перевод переносится по ID, не по номеру строки. Исходный русский текст всех прежних строк сохранён побуквенно; 22 архивных варианта оставлены для совместимости и помечены в контексте. Буквенные маркеры тяжести отделены от одноимённых букв сервисных машин.

**TEAM050_ru-en_v2.xlf** — тот же обновлённый набор в XLIFF 2.0. Исходные TEAM050_ru-en.xlsx / .xlf на 330 строк не перезаписывались: они остаются первоначальной переданной версией.

В v2 включены погрузка, топливо, заправочные очереди, случайные отказы, профилактическая защита, сообщения о моделях/сети и группы техники. Заполняются C (English) и при необходимости G (вопросы); инструкции и глоссарий внутри файла. Проверены все 407 строк после экспорта и оба листа визуально.


## Первоначальный пакет — архив

Для нового перевода передавайте **TEAM050_ru-en_v2.xlsx**. Ниже описан первоначальный **TEAM050_ru-en.xlsx**. В нём два листа:

- **Перевод**: 330 уникальных строк, русский оригинал, пустая колонка English, контекст, защищённые вставки, исходные места и колонка для вопросов. Заполняются C и при необходимости G. Заголовки и ID закреплены; доступна фильтрация.
- **Инструкция**: правила, область перевода, глоссарий и пояснение показателей loaded / delivered / processed.

Переводчик возвращает заполненный XLSX. Исходный русский текст и ID менять нельзя. Не удалять строки и защищённые вставки. Каталог пока не содержит готовых английских переводов.

**TEAM050_ru-en.xlf** — тот же набор в XLIFF 2.0 для CAT-систем. Источник `ru`, перевод `en`, цели пустые, переменные защищены inline-тегами `ph`. Если переводчик выбирает этот формат, заполняется XLIFF; параллельно заполнять оба файла не требуется.

## Для разработчика

Пакет готовит текст для перевода. Подключение языка в программе — следующая работа: каталог и переключатель, форматирование чисел/дат, единицы и множественное число, сообщения движка, проверка длинных строк. Ранее сохранённые русские события и отчёты автоматически не переводятся.

XLIFF можно заново собрать из нужных checkout командой из корня main:

```powershell
node scripts/export-localization.mjs . ..\team-050-3d-preview
```

Нужны установленные зависимости интерфейса main (`npm ci` в `team/mine/ui`). Экспорт создаёт пустой переводческий пакет: **не запускайте его поверх уже заполненного переводчиком файла**. XLSX сохранён также в `outputs/team050-localization/TEAM050_ru-en.xlsx`; служебные изображения не являются частью пакета для переводчика.

Обновлённый экспорт без перезаписи исходного пакета:

```powershell
node scripts/export-localization.mjs --output localization/TEAM050_ru-en_v2.xlf .
python scripts/merge-localization.py localization/TEAM050_ru-en.xlf localization/TEAM050_ru-en_v2.xlf
```

Вторая команда сохраняет отсутствующие старые единицы и переносит непустой перевод по совпадающему ID только при неизменном оригинале. Она не форматирует смешанное XML-содержимое, чтобы сохранить пробелы около защищённых вставок. XLSX готовится из итогового XLIFF; его таблица сверена с теми же ID и текстами.

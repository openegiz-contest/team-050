# Пакет перевода Team 050: русский → английский

## Что передать переводчику

**TEAM050_ru-en.xlsx** — основной файл. В нём два листа:

- **Перевод**: 330 уникальных строк, русский оригинал, пустая колонка English, контекст, защищённые вставки, исходные места и колонка для вопросов. Заполняются C и при необходимости G. Заголовки и ID закреплены; доступна фильтрация.
- **Инструкция**: правила, область перевода, глоссарий и пояснение показателей loaded / delivered / processed.

Переводчик возвращает заполненный XLSX. Исходный русский текст и ID менять нельзя. Не удалять строки и защищённые вставки. Каталог пока не содержит готовых английских переводов.

**TEAM050_ru-en.xlf** — тот же набор в XLIFF 2.0 для CAT-систем. Источник `ru`, перевод `en`, цели пустые, переменные защищены inline-тегами `ph`. Если переводчик выбирает этот формат, заполняется XLIFF; параллельно заполнять оба файла не требуется.

## Покрытие

Снимок исходников от 24 октября 2026 года:

- `main`, коммит `f280c2897de711e855f3eef2a062184bf854bb54`;
- `codex/3d-map-correct-vehicle-placement`, коммит `0b8c852e5f77591bf2a39a55fc57b34058c2c25a`.

Проверены русские строковые литералы TypeScript и Go, видимый HTML и атрибуты доступности/подсказок, названия объектов JSON и собственные панели Grafana в `team/mine/`. Включены 2D/3D, роли, состояния, поломки, ремонт, выездные машины, сообщения команд, валидация, журнал и серверная диагностика. Одинаковые строки объединены; сохранены 663 места использования в двух ревизиях. Ветку 3D экспортировали из отдельного checkout, не объединяя её с main.

Не входят проектная документация, сторонние интерфейсы платформы/браузера и текст внутри изображений или GLB-текстур. Английские технические идентификаторы, имена полей JSON, команды протокола и имена файлов переводить не нужно.

Строки с `{value_N}` — шаблоны с динамическими вставками. В колонке E и заметках XLIFF указан смысл выражения. Строки Go иногда являются фрагментами составной фразы; пробелы и разделители сохраняются. Не менять printf-спецификаторы, URL и коды объектов.

## Проверка пакета

- XLIFF разобран XML-парсером, все 330 ID уникальны.
- В сохранённом XLSX сверены все ID и русские оригиналы с XLIFF; английские поля пустые.
- Проверены закрепление A:B и строк 1:5, наличие таблицы с фильтрами и совпадение итоговой копии.
- Просмотрены изображения обоих листов.

## Для разработчика

Пакет готовит текст для перевода. Подключение языка в программе — следующая работа: каталог и переключатель, форматирование чисел/дат, единицы и множественное число, сообщения движка, проверка длинных строк. Ранее сохранённые русские события и отчёты автоматически не переводятся.

XLIFF можно заново собрать из нужных checkout командой из корня main:

```powershell
node scripts/export-localization.mjs . ..\team-050-3d-preview
```

Нужны установленные зависимости интерфейса main (`npm ci` в `team/mine/ui`). Экспорт создаёт пустой переводческий пакет: **не запускайте его поверх уже заполненного переводчиком файла**. XLSX сохранён также в `outputs/team050-localization/TEAM050_ru-en.xlsx`; служебные изображения не являются частью пакета для переводчика.

# Погрузка, топливо и случайные отказы

Актуальные правила на 25 октября 2026 года. Проект представляет условный учебный карьер. Ниже — параметры игровой симуляции, выбранные для наблюдения решений за одну смену.

## Погрузка

Для каждого самосвала и номера рейса выбирается целая масса от **230 до 250 т включительно** с равной вероятностью; среднее распределения — 240 т. Выбор сохраняется в течение погрузки. Ковш 29 м³ × наполнение 0,9 × плотность 1,7 т/м³ даёт обычную подачу 44,37 т. Последний ковш дозируется до выбранной массы; кузов ограничен 160 м³. Шесть подач занимают 300 секунд, постановка — ещё 60 секунд. При этих настройках весь диапазон помещается в кузов и требует шесть подач.

250 т — игровое отклонение по решению команды; номинал исходной модели техники остаётся 240 т. Это не рекомендация эксплуатировать реальную машину с превышением паспортной нагрузки.

Во вкладке «Погрузка и топливо» показаны число завершённых загрузок, средняя, минимум и максимум. В общий погруженный тоннаж входят также незавершённые погрузки; средняя считается только по завершённым. Если погрузку прервал отказ, уже погруженная масса сохраняется и может быть доставлена частичным рейсом. План по-прежнему считается по переработанной руде. Исходные мощности дробилок и норматив 93–95 тыс. т не пересчитываются автоматически.

Пример расчётного 12-часового прогона с фиксированным seed и автоматическим проверочным управлением ремонтом: **407 завершённых загрузок, 230–250 т, средняя 240,16 т**. Это проверочный сценарий, а не новый норматив и не результат действий пользователя.

## Топливо самосвалов

| Настройка | Значение по умолчанию |
|---|---:|
| Бак | 1800 л |
| В начале смены | 55–75% бака, отдельно для каждой машины |
| Движение с грузом | 180 л/модельный час |
| Движение без груза | 120 л/модельный час |
| Погрузка, постановка и разгрузка | 70 л/модельный час |
| Производственные очереди | 18 л/модельный час |
| Неисправность, ремонт, профилактика, очередь на заправку | Двигатель выключен |
| Колонка | 150 л/модельную минуту |
| Автоматическое направление | Остаток ниже 25% |
| R1 / R2 | По одной колонке и отдельной очереди FIFO |

Расход зависит от модельного времени: пауза его останавливает, ускорение не меняет литры на модельный час. При самостоятельной поездке с неисправностью топливо расходуется; на буксире — нет.

Автозаправка выбирает ближайшую площадку по длинам дорог. Механик может выбрать площадку вручную кнопкой «Направить на заправку». При движении команда выполняется на ближайшем узле, при погрузке/разгрузке — после окончания операции. Машина проходит реальное расстояние, ждёт колонку, постепенно пополняет бак до полного и возвращается к назначению; груз не исчезает. Колонка работает независимо от ремонтной бригады, даже если бригада на выезде.

Если топливо всё же закончилось, машина останавливается в фактической точке дороги. Механик вызывает эвакуатор; он доставляет её на R1/R2 в очередь заправки. Фиктивный ремонт не назначается. Уровень бака не бывает отрицательным. Отчёт и телеметрия содержат начальный остаток, расход, добавленный объём, остаток, число заправок, ожидание и время отвлечения на заправку. Выполняется баланс `начальное + заправлено = израсходовано + остаток`.

Топливо сервисных машин и эвакуатора в этой версии не рассчитывается. Резервные самосвалы ещё не вводятся в симуляцию.

## Случайные поломки

В первые 30 модельных минут новой смены случайных отказов нет. Далее для каждой машины интервалы имеют экспоненциальное распределение со средним **12 модельных часов**. Для двадцати постоянно работающих машин это около двадцати потенциальных событий за смену; фактических отказов обычно меньше из-за пропуска недоступных машин. Это настройка сложности, а не статистика реального предприятия.

Тяжесть потенциального отказа: 65% лёгких, 25% средних, 10% тяжёлых. Для стоящей без назначения, уже неисправной, обслуживаемой или заправляющейся машины событие пропускается. Ручной вызов остаётся для демонстраций. Поломки дробилок отдельно пока не моделируются.

После завершённой профилактики машина защищена от случайных отказов два модельных часа. Предотвращённое событие записывается в журнал. Ручная учебная поломка эту защиту не учитывает.

Seed, все потенциальные случайные события, выполненные ручные события и курсоры сохранены в состоянии. «Повтор» сохраняет исходное топливо, последовательность масс по рейсам, план, маршруты и потенциальные отказы. Разные решения о профилактике и занятости могут предотвратить разные отказы — это ожидаемый результат сравнения. Повтор не дублирует случайные события из журнала фактически случившихся отказов.

## Настройки и обновление старой смены

Необязательный объект `operations` в `team/mine/config/site.json` переопределяет значения из `domain/operations.go`: `load_spread_t`, `tank_l`, `loaded_lph`, `empty_lph`, `idle_lph`, `work_lph`, `pump_lpm`, `refuel_fraction`, `failure_mean_seconds`, `prevention_protection_seconds`. Отчёт содержит эффективную конфигурацию.

При обновлении существующей смены сохраняются её время, груз, ремонты и маршруты. Топливный учёт начинается с момента обновления; прошлый расход не выдумывается. Случайные события до этого момента не воспроизводятся задним числом. Старые отчёты не переписываются. Для изменённого файла конфигурации необходим новый каталог данных; движок защищает существующее сохранение от несовместимого сценария.

## Проверка

`cd team/mine && go test ./... -v` проверяет полный 12-часовой расчёт с ремонтом и заправкой, сохранение балансов, диапазон масс, независимость очередей, повтор и восстановление, сервис/профилактику/тяжёлый ремонт и эвакуацию с пустым баком. В рабочем интерфейсе вкладка статистики и карточка машины получают эти показатели из подтверждённого кадра Ditto.

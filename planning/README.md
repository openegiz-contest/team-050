# Выбранная схема участка

Схема выбрана командой как начальная карта условного участка. Она задаёт связи дорог и условные расстояния, но не воспроизводит физическую геометрию Актогая и выполнена не в масштабе. Цифровая карта стенда строится по конфигурации модели; исходная схема ниже служит для чтения графа и маршрутов.

## Файлы

- [Конфигурация узлов, дорог и маршрутов](../team/mine/config/site.json).
- [Параметры и источники](../ПАРАМЕТРЫ_СИМУЛЯЦИИ.md).

Откройте исходник через [app.diagrams.net](https://app.diagrams.net/), выберите открытие файла с устройства и укажите `.drawio`. Расстояния являются подписями, а не автоматически вычисляются по масштабу; после изменения дорог их нужно пересчитать отдельно.

## Обозначения

- E1–E4: четыре места погрузки, по экскаватору на каждом.
- C1–C3: три независимые дробилки с приёмными бункерами.
- R1–R2: две ремонтные площадки, по одной бригаде; сервисные машины базируются на этих площадках.
- P: общий гараж / стоянка. Текущая модель выпускает отсюда 20 рабочих машин. Пять резервных машин входят в полный замысел команды, но пока не моделируются.
- J1–J4: перекрёстки.
- M1–M6: готовые шаблоны маршрутов. Дороги общие и двусторонние; грузовой рейс идёт от E к C, возврат — в обратном направлении.

## Маршруты

| Маршрут | Последовательность узлов | Расстояние в одну сторону | Назначение |
|---|---|---:|---|
| M1 | E1 → J1 → J3 → C1 | 1,9 км | Основной |
| M2 | E2 → J1 → J3 → C2 | 2,1 км | Основной |
| M3 | E3 → J2 → J4 → C2 | 2,3 км | Основной |
| M4 | E4 → J2 → J4 → C3 | 2,3 км | Основной |
| M5 | E1 → J1 → J2 → J4 → J3 → C1 | 3,2 км | Объезд M1 |
| M6 | E4 → J2 → J1 → J3 → J4 → C3 | 3,4 км | Объезд M4 |

Условные длины отрезков: E1–J1 0,5 км; E2–J1 0,6 км; E3–J2 0,7 км; E4–J2 0,8 км; J1–J3 0,9 км; J2–J4 1,0 км; J1–J2 и J3–J4 по 0,6 км; J3–C1 и J4–C3 по 0,5 км; J3–C2 и J4–C2 по 0,6 км. Суммы маршрутов сверены с этими отрезками.

Служебные подъезды не входят в шесть грузовых маршрутов: P–J1 0,6 км; R1–J2 0,4 км; R2–J4 0,3 км. Время поездки на обслуживание включает дорогу до перекрёстка и служебный подъезд.

## Маршрут диспетчера

Диспетчер может назначить шаблон M1–M6 или собрать индивидуальный связный путь по существующим дорогам и выбрать пункт назначения. Маршрут одной машины можно менять независимо от остальных. Интерфейс показывает расстояние и расчётное время; изменение пути движущейся машины применяется в ближайшей допустимой точке без мгновенного перемещения. Создавать новые физические дороги нельзя.

## Допущения и ограничения схемы

Все расстояния заданы для симуляции и не взяты из производственных данных. Цветные линии исходной схемы выделяют шаблоны и не обозначают отдельные полосы движения. Пересечение линий без обозначенного узла не создаёт перекрёсток. Дорожная пропускная способность, разъезды, уклоны, столкновения и физические заторы не моделируются.

Для первого архивного прогона использовались C1 — 2986,67 т/ч, C2 — 3349,33 т/ч, C3 — 3136 / 3264 т/ч с чередованием каждые 67,5 модельной минуты, бункеры по 720 т. Эти значения — параметры симуляции. Расчёты: [ПАРАМЕТРЫ_СИМУЛЯЦИИ.md](../ПАРАМЕТРЫ_СИМУЛЯЦИИ.md).

# Выбранная схема участка

Схема подготовлена и выбрана командой 21 октября 2026 года как исходная карта модели. Принимаются показанная сеть дорог, расположение объектов и подписанные расстояния. Схема не воспроизводит фактическую геометрию Актогая и допускает последующую корректировку. Имена файлов сохраняют слово «ПРИМЕР» от исходного макета.

## Файлы

- [Редактируемый исходник draw.io](ПРИМЕР_КАРТЫ_КАРЬЕРА.drawio).
- [Изображение PNG](ПРИМЕР_КАРТЫ_КАРЬЕРА.png).
- [Векторное изображение SVG](ПРИМЕР_КАРТЫ_КАРЬЕРА.svg).

Открыть исходник: зайти на [app.diagrams.net](https://app.diagrams.net/), выбрать открытие файла с устройства и указать `.drawio`. Объекты и соединительные линии редактируются. Расстояния являются подписями, а не автоматически вычисляются по масштабу рисунка: после изменения дорог их нужно пересчитать отдельно.

## Обозначения

- E1–E4: четыре места погрузки, по экскаватору на каждом.
- C1–C3: три независимые дробилки с приёмными бункерами.
- R1–R2: две ремонтные площадки, по одной бригаде; заправка с отдельной очередью.
- P: стоянка пяти резервных машин; первоначально рабочих самосвалов — 20.
- J1–J4: перекрёстки.
- M1–M6: шесть готовых шаблонов для назначения самосвалам. Они не ограничивают число пользовательских маршрутов. Дороги общие, двусторонние; в шаблонах грузовой рейс направлен от E к C, возврат идёт в обратном направлении.

## Маршруты

| Маршрут | Последовательность узлов | Расстояние в одну сторону | Назначение |
|---|---|---:|---|
| M1 | E1 → J1 → J3 → C1 | 1,9 км | Основной |
| M2 | E2 → J1 → J3 → C2 | 2,1 км | Основной |
| M3 | E3 → J2 → J4 → C2 | 2,3 км | Основной |
| M4 | E4 → J2 → J4 → C3 | 2,3 км | Основной |
| M5 | E1 → J1 → J2 → J4 → J3 → C1 | 3,2 км | Объезд M1 при недоступности J1–J3 |
| M6 | E4 → J2 → J1 → J3 → J4 → C3 | 3,4 км | Объезд M4 при недоступности J2–J4 |

Условные длины отрезков: E1–J1 0,5 км; E2–J1 0,6 км; E3–J2 0,7 км; E4–J2 0,8 км; J1–J3 0,9 км; J2–J4 1,0 км; J1–J2 и J3–J4 по 0,6 км; J3–C1 и J4–C3 по 0,5 км; J3–C2 и J4–C2 по 0,6 км. Суммы расстояний маршрутов сверены с этими отрезками.

Служебные подъезды не входят в шесть грузовых маршрутов: P–J1 0,6 км; R1–J2 0,4 км; R2–J4 0,3 км. Время поездки на обслуживание включает дорогу до соответствующего перекрёстка и служебный подъезд.

## Индивидуальные маршруты диспетчера

Диспетчер может самостоятельно составлять путь для каждого самосвала по существующим дорогам выбранной схемы. Он назначает шаблон M1–M6 либо связную последовательность дорожных узлов и пункт назначения. Изменение назначения одной машины не меняет маршруты остальных.

Планируемый порядок: выбрать самосвал → указать путь на карте → увидеть расстояние и расчётное время → назначить маршрут. Связность пути и доступность отрезков проверяются до назначения. Создание новых физических дорог в эту функцию не входит.

Новый путь движущейся машины применяется в ближайшей допустимой точке, без мгновенного перемещения. Назначение учитывает состояние самосвала и наличие груза. Шаблоны и пользовательские пути используют одни и те же дороги, расстояния и правила движения.

Это требования будущей функции, не реализованный интерфейс. Отдельное редактирование обратного пути и сохранение пользовательского пути как нового общего шаблона пока не согласованы.

## Допущения и ограничения схемы

Все расстояния заданы для модели, не взяты из производственных данных. Схема не в масштабе. Цветные линии выделяют готовые шаблоны и не означают отдельные полосы движения. Соединение дорог есть в обозначенных узлах; пересечение линий без узла само по себе не задаёт перекрёсток.

Пропускная способность дорог, разъезды, ограничения по уклону, вместимость очередей, бункеров и заправок ещё не определены. Размещение объектов не задаёт распределение 20 работающих машин и не утверждает мощности дробилок. Три дробилки показаны без привязки к медленному/быстрому исполнению до отдельного согласования.
